# Исходники изображений

В git попали только те исходники, из которых ещё можно пересобрать ассеты сайта.
Всё, что отдаётся браузеру, лежит в `public/images/` и собирается заранее.

| Файл здесь | Куда попадает |
|---|---|
| `baza.jpg` | `public/images/baza-1280.{jpg,webp}` |
| `dyno.jpg` | `public/images/dyno-1280.{jpg,webp}` |
| `turbo.jpg` | `public/images/turbo-960.{jpg,webp}` |

Остальные исходники (полноразмерный `main_page.jpg`, дубли `gunrace/kolenka/olego/tatarstan/telegram`)
удалены из рабочего дерева: их готовые версии уже лежат в `public/images/`.
Полные исходники при необходимости достаются из истории git.

## PDF-каталог

`public/zc33s_catalog_s.pdf` (≈15 МБ) — файл, который скачивается кнопкой на `/catalog`.
Копия в корне репозитория и нарезка `catalog-*_part_*.pdf` удалены как неиспользуемые.

Правила `.gitignore` не дают снова закоммитить крупные PDF и исходники картинок в корне.
Если понадобится хранить такие файлы в репозитории — подключайте Git LFS.
