# Формат карточек товара (`card.txt`)

Карточки витрин читаются из папок `TuningCards/` (прошивки) и `CustomCards/`
(компоненты). Каждая карточка — отдельная папка: текстовый файл `card.txt` и
вложенная папка с изображениями (например, `images/`). Имя папки используется как
идентификатор карточки и как запасное название, если поле `HEADER` не заполнено.

Поля пишутся заглавными буквами в виде `ПОЛЕ - значение`. Значение может занимать
несколько строк — оно заканчивается там, где начинается следующее поле. Порядок полей
произвольный, все поля кроме `HEADER` необязательны.

| Поле | Что это | Формат значения |
| --- | --- | --- |
| `HEADER` | Название карточки | одна строка |
| `HIGHLIGHTS` | Ключевые параметры, которые видны на карточке до открытия | по одному в строке, показываются первые четыре |
| `SUMMARY` | Назначение: короткий абзац без маркетинговых формулировок | связный текст |
| `SPECS` | Основные характеристики | строки вида `Параметр — значение` |
| `POWER` | Заявление о мощности — только как ориентировочный расчётный показатель | связный текст |
| `REQUIRED` | Требования к конфигурации, раздел «Обязательно» | по одному в строке |
| `RECOMMENDED` | Требования к конфигурации, раздел «Рекомендуется» | по одному в строке |
| `INCLUDED` | Что входит в стоимость | по одному в строке |
| `VARIANTS` | Варианты приобретения | строки вида `65 000 ₽ — условие`; строки без цены в начале выводятся как пояснения |
| `WARRANTY` | Срок гарантии | например, `6 месяцев` |
| `TESTS` | Измеренный результат тестового автомобиля | строки вида `Параметр — значение` |
| `PRICE_NOTE` | Пояснение к цене (переопределяет общее из `src/data/siteConfig.js`) | связный текст |
| `PRICE` | Ориентировочная стоимость | например, `65 000 – 80 000 ₽` |
| `DESC` | Свободный текст (устаревшее поле) | показывается вместо `SUMMARY`, если новых полей нет |

Разделитель в парах «Параметр — значение» — длинное тире (`—`) с пробелами вокруг,
поэтому артикулы вида `TD02L11-025*075WDS-F3.4` не разбиваются на части.

## Пример

```text
HEADER - Турбина GR30

HIGHLIGHTS -
Гибридная турбина
Наддув до 1.6 бар
МКПП / АКПП
≈215–220 л.с.

SUMMARY -
Гибридная турбина GunRace GR30 для Suzuki Swift Sport ZC33S.

SPECS -
Базовая турбина — Mitsubishi TD02, 13900-86P01
Рекомендуемый наддув — до 1.6 бар
Совместимость по коробке передач — механическая и автоматическая

POWER -
Ориентировочная расчётная мощность — до 215–220 л.с. при соответствующей конфигурации
автомобиля, топливе с октановым числом 100 и выше и корректной настройке ECU.

REQUIRED -
Увеличенный интеркулер
Даунпайп

RECOMMENDED -
Модифицированная выпускная система

VARIANTS -
65 000 ₽ — При изготовлении с использованием турбины клиента
80 000 ₽ — При изготовлении из турбины-донора SST/GunRace

WARRANTY - 6 месяцев

PRICE - 65 000 – 80 000 ₽
```

## Требования к тексту карточек

1. Тон — профессиональный и технический, без рекламных гипербол. Разговорные сокращения
   не используются: вместо «встают болтон» — «устанавливается в штатные точки крепления
   без доработки кузова», вместо «9лепестков» — «вал с девятью лопастями».
2. Мощность указывается только как ориентировочный расчётный показатель с условиями,
   например: «Ориентировочная расчётная мощность — до 215–220 л.с. при соответствующей
   конфигурации автомобиля и корректной настройке ECU». Формулировки вида
   «турбина выдаёт 220 сил» не используются.
3. Измеренные данные приводятся только при наличии реального замера и только в поле
   `TESTS` — тогда в карточке появляется отдельный блок «Результат тестового
   автомобиля». Расчётный показатель и измеренный результат не смешиваются.

   ```text
   TESTS -
   Автомобиль — Suzuki Swift Sport ZC33S, 2019
   Пробег — 78 000 км
   Конфигурация — GR30, увеличенный интеркулер, даунпайп, выпуск 60 мм
   Топливо — АИ-100
   Давление наддува — 1.6 бар
   Стенд — (наименование и тип стенда)
   Температура — +18 °C
   Мощность — (значение) л.с.
   Крутящий момент — (значение) Н·м
   Дата измерения — (дата)
   ```

4. Цена не подаётся как окончательная сумма сделки. Если помимо изделия возможны
   дополнительные работы, добавляется `PRICE_NOTE`; по умолчанию выводится формулировка
   из `src/data/siteConfig.js`: «Стоимость указана за изделие. Настройка, установка,
   доставка и дополнительные работы рассчитываются отдельно, если прямо не указано
   иное».
5. Блок «Важно» и ссылка на страницу гарантии (`/warranty`) добавляются в карточку
   автоматически — дублировать их в тексте не нужно.
