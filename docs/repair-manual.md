# Руководство по ремонту: пробный раздел

Подготовлено для Suzuki Swift Sport ZC33S, двигатель K14C. Включает 11 документов ветки «Зажигание» исходного руководства AJPHSB0P / 42-52R20. Применимость ко всем годам выпуска не заявляется. Полное руководство, каталоги DTC, все варианты автомобилей и отдельные PDF в пробу не входят.

## Повторный импорт

Требуются зависимости проекта и UnRAR (на Windows используется стандартный путь установки WinRAR; можно указать `--unrar`). Исходный RAR в репозитории не хранится.

```powershell
npm ci
npm run manual:import -- --archive "C:\path\RU V3 Руководство по ремонту Suzuki Swift для Firefox.rar"
npm run manual:test
npm run manual:check
npm run check:anchors
npm run build
```

Кодировка списка UnRAR на текущей Windows — OEM 866. На другой системе можно явно задать переменную среды `UNRAR_LIST_ENCODING`, например `utf-8` или `windows-1251`. XML читается в UTF-8. Архив передаётся явно; импортёр не ищет файлы в Downloads автоматически.

Команда импорта готовит данные в отдельном временном каталоге. После проверки всех 11 документов заменяет только свой каталог `public/manual`. При ошибке исходные подготовленные данные сохраняются. Сборка и проверки подготовленных файлов работают без RAR и UnRAR.

## Данные

- `public/manual/index.json` — порядок материалов, названия, группы, цели ссылок и подписи, добавляемые оригинальными шаблонами.
- `public/manual/search.json` — индекс заголовков и полного текста.
- `public/manual/documents/` — отдельные документы в виде дерева разрешённых узлов.
- `public/manual/images/` — только иллюстрации, встречающиеся в пробе, в исходном качестве JPG.
- `public/manual/report.json` — SHA-256 источников и подготовленных файлов, контрольные количества, ссылки и список целей за пределами пробы.

Исходные XML и шаблоны в `scripts/manual/fixtures/` служат для воспроизводимых проверок сохранности. Атрибуты и скрипты оригинального просмотрщика не исполняются. Неизвестный значимый элемент или отсутствующая иллюстрация останавливают импорт.

## Ограничения и проверка

Ссылки на документы вне 11 материалов сохраняют название цели и явно сообщают, что материал пока не включён в пробный раздел. Наличие JPG для SWF не доказывает сохранение возможной интерактивности. Для статичных схем используются готовые JPG; качество мелких надписей оценивается при визуальной проверке.

Автоматические проверки импорта сопоставляют 12 вхождений иллюстраций, 5 таблиц, 9 диагностических групп, 18 ответов и 18 действий. Проверяется существование целей внутренних ссылок и якорей, включая `T1H303`.

Фактические результаты проверки интерфейса будут записаны после его реализации.
